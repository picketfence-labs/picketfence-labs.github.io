# SE Activity Tracking

[2026-11-09開始週のレポート](https://picketfence-labs.github.io/reports/se-activities/jp-se-weekly-20261109.html)

レポートは `reports/se-activities/jp-se-weekly-YYYYMMDD.html` の個別HTMLで公開します。日付は対象週の月曜日です。毎週、新しい対象週のHTMLを追加します。同じ週の改訂は `jp-se-weekly-YYYYMMDD-v2.html` のように版を付けます。

確認済みの単一HTMLを配置しmainへpushした後、Pages build成功、個別URLのHTTP応答・SHA-256と実ブラウザ表示を確認します。
