# SEアクティビティレポート

最新版は [reports/se-activities/](https://picketfence-labs.github.io/reports/se-activities/) で閲覧できます。

- `index.html` は最新の確認済みレポートです。
- `YYYY-MM-DD.html` は報告日ごとの保存版です。同日改訂は `YYYY-MM-DD-v2.html` のように別名で保存します。
- 集計・確認済みの自己完結HTMLを日付別ファイルへ追加し、同じbytesで `index.html` を更新してmainへpushします。
- Pagesのbuild成功、最新版と日付別URLのHTTP応答・SHA-256・ブラウザ操作を確認します。

初回の2026-11-10版は本人受入済みの日本語HTMLベースラインです。
