週ごとに `jp-se-weekly-YYYYMMDD.html`（対象週の月曜日）の固定URLを保持します。同じ週の更新はそのファイルを上書きし、v2等の改訂別HTMLは増やしません。次の週になっても過去の週のファイルを削除・上書きしません。

`jp-se-weekly.html`は現在週への互換用転送だけを置き、レポート本体は保持しません。週次公開時に現在週への転送先と上の一覧を更新します。確認済みHTMLを明示stageしてcommit/pushし、build・HTTP・生成物の全bytes一致・実ブラウザ表示を確認します。private入力・判断・再生成runは別途保持します。
